---
description: 리뷰와 빌드 검증을 마친 뒤 커밋(및 요청 시 PR)까지 진행한다
---

1. `code-review` 스킬로 현재 diff를 리뷰하고, 발견된 이슈를 반영한다.
2. `go build ./...`, `go vet ./...`, `go test ./...`로 최종 검증한다. 실패하면 커밋하지 않는다.
3. `git status`, `git diff`로 변경 내용을 확인하고, 커밋 메시지는 한국어로 작성한다 (변경 이유 중심, "무엇을"보다 "왜").
4. 커밋은 사용자에게 확인 후 진행한다. PR 생성이나 push는 명시적으로 요청받았을 때만 수행한다.
